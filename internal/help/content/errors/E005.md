# E005 — key doesn't match this project's casing

**Cause.** Every key in the tree must follow one project-wide convention,
`key_case` in `intent.config.yaml` — `kebab-case` (default) or `snake_case`.
This key uses the other one, or mixes both (`foo-bar_baz`).

The schema only checks a key's shape (lowercase letters, digits, underscores,
or hyphens, starting with a letter); the specific convention a project
requires is this rule's job.

**Fix.**

- Rename the key to match: `intent mv <addr> --rename <new-key>` — it
  cascades every `mitigates`/`dependsOn`/`fulfills`/`affects`/`relationships`
  edge and `{{ }}` prose reference to the new key across the whole tree, so
  nothing dangles.
- If this project actually wants the other convention, set `key_case` in
  `intent.config.yaml` instead of renaming every key.
